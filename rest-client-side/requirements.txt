# ─── Chauka Restaurant System — Requirements ──────────────────────────────
# Software needed to run the restaurant system.
# Install these BEFORE running the setup commands in cmd.txt.

# ─── Required ─────────────────────────────────────────────────────────────

# Node.js (JavaScript runtime)
# Version: 18 or higher (LTS recommended)
# Download: https://nodejs.org
# This also installs npm (package manager)
Node.js >= 18

# npm (comes bundled with Node.js)
# Used to install project dependencies
npm >= 9

# ─── Optional but recommended ─────────────────────────────────────────────

# pm2 (process manager — keeps the server running after terminal closes)
# Install: npm install -g pm2
# Download: https://pm2.io
pm2 (for background/always-on server)

# ─── Hardware ─────────────────────────────────────────────────────────────

# The server machine (runs node server.js):
#   - Windows PC or laptop
#   - Any OS (Windows, Mac, Linux)
#   - Connected to the restaurant's WiFi/LAN
#   - Stays on 24/7 (or reboots auto-start via pm2)

# Client devices (connect to the server via browser):
#   - Any device with a modern browser (Chrome, Safari, Edge, Firefox)
#   - Phones, tablets, laptops — no app install needed
#   - Must be on the same WiFi/LAN as the server

# ─── Screen summary ───────────────────────────────────────────────────────
