# ─── Chauka Restaurant System — Setup Commands ────────────────────────────
# Run these commands in the rest-client-side folder.
# Windows: open Command Prompt or PowerShell in this folder.
# Mac/Linux: open Terminal in this folder.

# ─── Step 1: Install Node.js (if not already installed) ───────────────────
# Download and install Node.js from: https://nodejs.org
# Choose the LTS version (v18+). This also installs npm.
# After installing, restart your terminal, then verify:

node --version
npm --version

# ─── Step 2: Configure the system ─────────────────────────────────────────
# Open the .env file in Notepad (or any text editor) and fill in:

notepad .env

# Required fields:
#   LICENSE_KEY=CHK-XXXX-XXXX-XXXX-XXXX
#   LICENSE_SERVER_URL=https://licenses.yourdomain.com
#
# Optional:
#   MANAGER_PIN=2468       (protects manager panel edits)
#   WHATSAPP_NUMBER=91...  (enables WhatsApp links)
#   PORT=3000              (default, change if 3000 is busy)

# ─── Step 3: Install dependencies ─────────────────────────────────────────
npm install

# ─── Step 4: Start the server ─────────────────────────────────────────────
npm start

# ─── Step 5: Open the Hub ─────────────────────────────────────────────────
# In a browser, go to:
#   http://localhost:3000/app/hub/
#
# The hub shows your server's LAN IP and QR codes for every screen.
# Connect other devices (tablets, phones, kitchen screen) using the
# LAN IP shown on the hub.

# ─── Useful commands ──────────────────────────────────────────────────────
# Start in background (keeps running after you close the terminal):
#   pm2 start server.js

# Stop background server:
#   pm2 stop server.js

# View logs:
#   pm2 logs

# Install pm2 globally (if not installed):
#   npm install -g pm2

# ─── Troubleshooting ──────────────────────────────────────────────────────
# Port 3000 already in use? Change port in .env:
#   PORT=3001
#
# Other devices can't connect? Check:
#   1. All devices are on the same WiFi
#   2. Windows Firewall allows port 3000
#   3. Use the LAN IP from the hub, not localhost
#
# License locked? Check LICENSE_KEY is correct and active.
